# Atlantic Cinema

## Proyecto de Graduación

**Implementación de Plataforma Web para Venta de Tickets, Pasarela de Pago y Facturación Electrónica para Cine Local**

---

## Estado del proyecto

🚧 En desarrollo.

Actualmente se encuentra en la etapa de implementación del backend utilizando Laravel y PostgreSQL.

---

## Tecnologías utilizadas

### Backend
- Laravel 13
- PHP 8.4

### Base de datos
- PostgreSQL 17
- Docker

### Frontend
- React
- Vite

### Herramientas
- Visual Studio Code
- Git
- GitHub
- DBeaver

---

## Arquitectura

- Frontend independiente desarrollado con React.
- Backend desarrollado con Laravel como API REST.
- Base de datos PostgreSQL ejecutándose mediante Docker.
